## 13.3

发布日期：2025-02-04

#### 增强功能

* 允许新闻站点地图项通过新的过滤器 `Yoast\WP\News\publication_language` 更改语言。感谢 [dgwatkins](https://github.com/dgwatkins)。

#### 错误修复

* 修复了 WordPress 6.7 中关于 `_load_textdomain_just_in_time` 加载错误导致的 PHP 提示。

#### 其他

* 将 Yoast SEO 最低要求版本设置为 24.4。
* 将最低支持的 WordPress 版本设置为 6.5。
* 将“WordPress 测试至”版本设置为 6.7。

## 13.2

发布日期：2024-03-05

#### 增强功能

* 新增 `wpseo_news_sitemap_content` 过滤器，用于向 XML 站点地图追加自定义内容。感谢 @wccoder。
* 此 PR 引入了一种通过使用 TranslationPress 服务来获取 Yoast News SEO 翻译的新方式。我们不再需要在每次发布时附带所有翻译文件，而是可以根据用户的安装配置按需加载翻译。这意味着插件发布包更小，用户服务器上的冗余也更少。

#### 错误修复

* 修复了激活时会抛出警告的问题。
* 修复了在出版物名称中使用 `&` 字符会破坏 XML 站点地图的问题。

#### 其他

* 放弃对 PHP 5.6、7.0 和 7.1 的兼容性支持。
* 提升了安全策略的可发现性。
* 将最低要求的 Yoast SEO 版本设置为 22.2。
* 将最低支持的 WordPress 版本设置为 6.3。
* 将测试通过的 WordPress 最高版本设置为 6.4。
* 该插件与 PHP 8.3 没有已知的不兼容问题。
* 通过 [WP]Packagist 引入此包的用户现在可以使用 `composer/installers` v2。

## 13.1

发布日期：2021-11-16

#### 功能增强

* 巨大的性能提升：将 XML 新闻站点地图迁移至基于我们的 Indexables 架构。
* 从 XML 新闻站点地图中移除图片，因为它们在此处没有作用，这进一步提升了性能。

#### 其他

* 在可能包含在新闻站点地图的文章类型中，排除了附件和非索引文章类型。

## 12.7

发布日期：2021-04-06

#### 功能增强

* 在 Elementor 编辑器和区块编辑器的 Yoast SEO 侧边栏中新增新闻模块。
* 将新闻元数据框中的“从新闻站点地图中排除”和“Googlebot-News 索引”设置合并为单一设置：“从 Google 新闻中排除此文章”。因为这两个设置目的相同，都是将内容从新闻站点地图中排除。
* 从新闻站点地图和设置中移除“默认体裁”选项，因为 Google 已不再支持 Google 新闻中文章的“体裁”分类。

#### 其他

* 将 WordPress 测试版本上限设为 5.7，最低支持版本设为 5.6。

#### 错误修复

* 修复了特定条件（例如使用不同管理语言）导致无限循环的错误。
* 修复了新闻 SEO 选项页面上的“混合内容”警告。
