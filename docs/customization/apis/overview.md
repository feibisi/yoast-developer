Yoast SEO exposes several APIs, which are designed to help advanced users, developers, and integrators to access and manipulate our data and outputs.

- [Our Rest API](docs/customization/apis/rest-api), for accessing Yoast SEO metadata headlessly.
- [Our Surfaces API](docs/customization/apis/surfaces-api), for returning information about (or properties of) a URL or post.
- [Our Metadata API](docs/customization/apis/metadata-api), for adding or altering our meta tag outputs in the `<head>` of a document.
- [Our Schema API](https://developer.yoast.com/features/schema/api), for altering our schema.org output.
