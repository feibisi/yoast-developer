This documentation provides information about how [Yoast SEO](https://yoast.com/product/yoast-seo-wordpress/) integrates with [IndexNow](https://www.indexnow.org/).

## Ping on update
Similarly to how we handle [XML Sitemaps](docs/features/integrations/features/xml-sitemaps/functional-specification), whenever a URL is updated (as a result of a post, page, or URL being created/updated), then the system should ping an IndexNow endpoint.
